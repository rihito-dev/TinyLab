# Goal

Template: replace the prompts below for your project. Keep one current goal; retain earlier goals in Git history or link an archived note.

- **Outcome:** What should become possible, and for whom?
- **Problem:** What observed difficulty makes this worth doing?
- **Success criteria:** What observable result would count as success?
- **Evidence needed:** Which experiment or source can support that judgment?
- **Budget:** Maximum time, money, and other resources.
- **Target date:** YYYY-MM-DD.
- **Stop or reconsider when:** What would make further work a poor use of resources?
- **Status:** planned / active / achieved / stopped.
- **Next action:** One concrete step.
