# Sources

Record one entry per source or acquired dataset. Link source IDs from research, experiments, and decisions. Prefer original publishers. A URL alone may not identify the version used.

Do not commit credentials, restricted datasets, or private material. When redistribution is not permitted, record a lawful retrieval procedure instead. Unknown rights are not permission to redistribute.

## SRC-XXX — Source title

- **Publisher / author:** Original provider.
- **URL or identifier:** Stable locator, document ID, or DOI.
- **Published / updated:** Provider's timestamp, or unknown.
- **Accessed / acquired:** Your timestamp with timezone.
- **Version and scope:** Edition, date range, population, units, and relevant page/table/section.
- **Acquisition:** Download, API, manual extraction, or other reproducible steps.
- **Local reference / hash:** Permitted artifact location and checksum if applicable; never a credential.
- **Transformations:** How the source became the input used.
- **License / usage terms:** Link and redistribution status; unknown if unverified.
- **Limitations:** Missing fields, coverage gaps, or unresolved questions.
- **Used by:** Experiment or decision links.
