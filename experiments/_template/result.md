# Result

Blank template — not executed. Replace prompts only with observed facts or explicitly labeled estimates.

- **Lifecycle status:** planned / running / completed / stopped.
- **Outcome:** not evaluated / supported / not supported / inconclusive.
- **Execution date:** YYYY-MM-DD, with timezone if relevant.
- **Plan commit:** Git commit containing the conditions used.
- **Inputs actually used:** Source IDs, versions, and hashes if applicable.

## Observations

Record measurements, units, denominators, exclusions, and uncertainty. Keep missing values distinct from zero. Link permitted artifacts or retrieval instructions.

## Comparison with the rule

Compare the observations with the acceptance and stopping rules. State which checks ran and which did not.

## Limitations and deviations

What remains unknown? What differed from the plan? Separate interpretation from measurement.

## Reproduction and next decision

Record the exact commands or steps actually used, the environment, and any access requirements. Link the decision or follow-up experiment. A rerun has not been verified unless it was performed and compared.
