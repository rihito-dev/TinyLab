# Non-goals

Template: list things your project deliberately will not do now. A boundary saves time only when it guides a real choice.

| Not doing now | Reason / cost avoided | Revisit when |
| --- | --- | --- |
| Replace with a concrete exclusion | Explain the tradeoff | State an observable trigger |

For TinyLab itself, the initial boundaries are:

- No CLI, application, database, or hosted service: the scaffold should be usable by copying files.
- No prescribed research domain or programming language: add those in projects that need them.
- No automated claim of scientific validity: templates organize evidence but cannot verify it.

When using this template for another project, replace these boundaries with your own. Link significant scope changes in [DECISIONS.md](../DECISIONS.md).
